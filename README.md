# trombone-tuner

Live tuner voor tenortrombone in Bes (vioolsleutel), voor op de lessenaar.

**Openen:** https://sjnirk.github.io/trombone-tuner/

- Toont de geschreven noot zoals op je blad (Bes-notatie: geschreven C klinkt als Bes) en de positie, met alternatieve posities.
- Naald in cent met advies (iets uitschuiven of inschuiven) en een spoor van de laatste 8 seconden.
- Stemming instelbaar van A = 430 tot 450 Hz.
- **Meespelen:** geopend vanuit de app (`?t=titel&n=noten&w=week`) toont de tuner het stuk in notenschrift. De noot die aan de beurt is licht op en schuift door zodra je hem raakt; elke noot kleurt naar hoe zuiver hij was, met een samenvatting aan het eind. Met `?doel=G4` toont hij alleen een doelnoot.

**Privacy:** alles gebeurt in je eigen browser. De microfoon gaat pas aan als je op Start drukt, er wordt niets opgenomen, opgeslagen of verstuurd. Deze repo bevat alleen de tunercode.
